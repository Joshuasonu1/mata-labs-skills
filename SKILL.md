# MATA Labs skills (bundle)

This bundle holds every skill as a subfolder. Pick the one that fits the task, then read `<folder>/SKILL.md` and follow it exactly (it may point to more files in the same folder, such as `polcomms-reels/ktr-edit-grammar.md`). Read `reel-production-core/SKILL.md` too for any reel build. ALWAYS read `HOUSE_RULES.md` first: it holds the user's standing rules and project notes.

| Folder | Use it for |
|---|---|
| `explainer-default` | Make a clean 45–90 second product demo video for any software product, rendered from code to MP4 with music. Airy light canvas, short centred lines the camera pushes into, the product's own UI rebuilt and shown up close as it is used (typing, results, tables, clicks), integrations, and a logo close. Use when someone wants a product demo, launch video, feature walkthrough or "how it works" video for an app, SaaS or tool. |
| `explainer-engaging` | Make a 10–30 second continuous-shot explainer for any product, rendered from code to MP4 with sound. One hero element (a ball, a cursor, a file, a message) travels through the product's workflow laid out as stations on one big canvas; the camera follows it, each station reacts as it passes, then the camera pulls out to reveal the whole journey. Use when someone wants an engaging, story-driven, one-take explainer or a loopable product animation. |
| `explainer-high-energy` | Make a 12–20 second high-energy motion-graphics promo for any product, rendered from code to MP4 with synthesised music. Fast beat-locked scene changes, kinetic typography, a shape that carries across every transition, a HUD frame. Use when someone wants a hype reel, teaser, launch sting or showreel-style promo for a product, app or brand. |

| `motion-broll` | Turn a talking-head video and its transcript into motion-graphic B-roll timed to the speaker's words, in a continuous one-shape style (one element that morphs and never cuts, driven by a cursor, spring motion). Use when someone gives a video (and ideally a transcript) and asks for motion graphics, B-roll, animated cutaways or overlays. |
| `object-separation` | Separate a person, product or hand from the background in a video, on the user's own computer with SAM 2. Scans the machine first to pick the right model size, then outputs the same video with the separated subject highlighted in green, plus frame-by-frame masks. Use when someone wants to separate, isolate, cut out or rotoscope something in a video. |

| `social-media-cover-designer` | Design premium cover images and profile banners for Facebook Pages, X (Twitter) headers, LinkedIn personal backgrounds and LinkedIn company Pages, built in Photoshop around the client's ORIGINAL portrait (never an AI face). Six design systems (cinematic, editorial, premium portrait, minimalist, documentary collage, political leadership), platform safe zones, Telugu/Hindi/English typography, AI-generated or stock background plates, and a scored QC pass. Use when the user asks for a cover photo, profile banner, header image, LinkedIn background, Facebook cover or X header for a person, leader, campaign or organisation. NOT for Instagram reel covers or ordinary feed posts. |
| `sound-effects` | Add a measured sound pass to a motion-graphics video made with Claude Code (HyperFrames, Remotion, GSAP, Claude Motion or the motion-broll skill). Builds a cue list, checks the music's beat grid against the kick drums, lands cuts on the beat, places one real sound effect per cue from a bundled CC0 library, mixes to -16 LUFS with true peaks below -4 dBFS measured on the exported MP4, and proves it with frames, waveforms and 5 timestamps for a human to check. Use when someone wants sound effects, sound design or music added to a motion-graphics video, or says their AI video sounds like cheap beeps. |
| `zptc-captions` | Add the "ZPTC style" negative-text captions to a reel - small white uppercase label over a big condensed uppercase line whose letters show the footage's inverted colours, in the lower band of the rounded footage frame - timed to the voiceover, as a burned-in MP4 and an editable Premiere Pro XML, with optional SFX. Use when the user says "ZPTC captions", "ZPTC style", "add captions like previous", "same captions as the election reels", or gives a Viresh Sir election reel plus a script to caption. |
