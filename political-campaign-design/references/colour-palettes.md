## Grading stack
1. Gradient Map / LUT 10–25% for mood.
2. Curves (S-curve; lifted blacks for a print feel).
3. Selective Colour to push the party colour.
4. Photo Filter over **all photos** in collages so they match.
5. Vignette 15–30% away from the text.
6. Grain layer (Overlay 25–35%) over everything, which unifies real photos and generated plates.
Desaturate-test: the face must still separate by luminance.
