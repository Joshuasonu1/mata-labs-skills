# MATA Labs skills

All Claude skills in one bundle (23 skills + house rules). Private repo.

- `SKILL.md` - index of every skill; Claude reads it first.
- `HOUSE_RULES.md` - standing rules and project notes.
- One folder per skill, each with its own `SKILL.md`.

## Restore on a new computer (Claude Code)
Copy each skill folder into `C:\Users\<name>\.claude\skills\`.

## Upload to claude.ai
Zip this whole folder as `mata-labs-skills` and upload it under Settings > Capabilities > Skills.
